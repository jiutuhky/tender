# 工作台空间卡片系统

工作台默认进入空间画布，“概览”保留矩阵列表入口。`/workspace?demo=1` 提供完整成果、正在生成、部分失败和大量资料四种独立场景。

## 产品模型

业务实体记录内容与核验状态；画布实例记录坐标、尺寸及容器；集合表达堆叠或文件夹。一个评分项可同时出现在集合与主画布，两个实例引用同一份业务对象。拖拽收纳不会改变文件路径、评分归属或大纲结构。

项目概要为摘要卡；商务与技术要求、评分、章节采用纸张与堆叠；大纲采用目录文稿；素材按文件、图片、视频呈现；文本笔记支持原位编辑。来源、响应与引用关系仅在相关对象选中时呈现。

处理状态与人工核验状态分别展示。真实适配器读取四矩阵与项目文件；大纲、章节和成稿由演示适配器提供。后续工作流可实现 `CanvasSource` 接口并声明实体的阅读、编辑能力。

## 操作

- 单击选中，双击或 Enter 打开；笔记进入原位编辑，点击完成、离开编辑区或 Ctrl / ⌘ + Enter 保存。
- Shift 点击或空白框选多选；G 组成堆叠，Shift + G 组成文件夹；上下文工具栏支持整理、配色、重命名、移出、解散和下载。
- 滚轮平移，Ctrl / ⌘ 加滚轮缩放；空格拖动画布；触屏支持单指平移与双指缩放。
- 堆叠原位散开，文件夹进入内部空间。Escape 逐层返回，相机与选择恢复。
- 箭头移动卡片，Shift 加箭头加大步长；四角调整尺寸，媒体保持比例。
- Ctrl / ⌘ + Z 撤销，Shift + Ctrl / ⌘ + Z 重做。移除画布实例保留服务端业务数据。
- N 添加笔记，Ctrl / ⌘ + K 搜索，0 适应内容，1 恢复 100%。支持粘贴文字与媒体文件。

## 数据与实现

- `frontend/lib/canvas/`：模型、真实及演示适配器、文件操作、坐标计算和测试。
- `frontend/app/workspace/_components/canvas/spatial/`：卡片、阅读层、指针手势、集合动效、独立空间状态与样式。
- 布局、集合和笔记按项目保存于当前浏览器，键为 `prose.canvas.v1:<projectId>`。演示导入的文件保存在 IndexedDB；服务端业务内容不进入布局快照。
- 逐帧拖拽与相机变换直接更新 DOM，释放后提交布局。相机持久化在滚轮停下后执行。大集合采用视口裁剪，初次展开聚焦前几排。
- 文件清单来自 workspace files，原文注册表用于来源映射。PDF 通过注册表关联独立的原件与预览接口；上传后先以原始文件预览，注册完成后在同一卡片中切换为服务端来源。上传保留目录相对路径，同名路径追加编号；部分失败可独立重试。
- 媒体代理透传 Range。当前上游返回完整文件时，代理补齐单段 206 / 416 响应；大文件的上游读取开销仍由既有文件服务承担。

## 验收记录

自动检查：`pnpm typecheck`、`pnpm lint`、`pnpm test:canvas`、`pnpm test:trace`、`pnpm build`。

浏览器检查覆盖：拖拽抓取偏移与保存、多选分组与撤销、拖入集合、四角比例缩放、嵌套文件夹、笔记编辑、评分阅读、焦点恢复、概览切换、文件夹中途反向、深浅主题与窄屏。

大量资料场景包含 200 条评分与 100 个素材；1440 × 1000 视口展开评分时挂载 16 张评分卡。

接口链路使用隔离的契约服务，经过实际 Next 同源代理，验证矩阵恢复、409 冲突重载、核验、应答标记、原文阅读、上传失败重试、同名保留、真实目录选择与子目录路径、PDF 异步就绪与原件 / OCR 合并、视频 Range。验收未调用真实模型生成，也未对真实项目写入测试数据。截图位于 `verification/`。
