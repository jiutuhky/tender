# 平面转向修订检查记录

本轮恢复第二版的 SVG 平面画法，仅修改转向的侧面补位、正面裁切与眼睛移出。默认正面，未接入产品。

- 全部 36 项动作通过实际按钮逐个选择；路径没有 NaN、Infinity 或 undefined，浏览器无运行错误。
- 默认待命 `yaw=0`，侧面层透明度为 0。
- 四帧分解：正面整体横向倍率 1；45° 约 0.971；90° 为 0.9；背面为 1。侧向保持饱满轮廓。
- 正面和半转可见双眼；侧向和背向双眼透明度为 0，并使用正面裁切窗口。
- 页面 Canvas 数量为 0，SolidRenderer 不存在；只加载 motion.js 和 design.js，没有 WebGL 渲染或三维视角控件。
- 快速切换情境正确收束至等待回应；动态减少动效后采用代表姿态，彩带强度为 0。
- 1120 / 736 / 360 / 320px、浅深两主题均无横向溢出或越界文字、按钮与 SVG。
- 二维彩带、36 项通用语义、无角标原则保留。没有增加材质、高光、投影或默认斜视。
