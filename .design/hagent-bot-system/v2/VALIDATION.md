## 边界

- 六动作对照区有意重复播放事件，供横向比较；生产事件必须去重并单次播放。
- 静态终态的角色停止更新后，页面仍可能因另一个可见对照角色继续使用共享 rAF；不把“全页 rAF 存在”误判为该终态仍在动。
- 通用状态需由产品适配器提供真实事实。样片不连接后端，不实现真实审批、重试、发送或取消。
- 普通工作态的候选稳定/最低驻留、任务 ID、事件过期、业务恢复为设计确认后接入工作；快速切换演示故意绕过驻留。
- 没有做实际用户的状态辨识实验、真机触屏、完整读屏软件、跨浏览器或生产负载性能测试；不能承诺在 20px 单凭身体就能猜中全部状态。
- 本轮仅修改设计文件，未运行产品 typecheck / lint；实际接入产品时按仓库质量门验证。
