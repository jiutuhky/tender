# 标书知识库

整体结构树。

## 1. 企业资产库

> 结构化字段为主 + 原件附件，零容错，只引用不生成

### 1.1 主体资质

- 基础证照（营业执照、开户许可、税务登记）
- 行业资质认证（ISO 体系、CMMI、安全生产许可、行业准入…）
- 信用与荣誉（信用等级、获奖证书、无违法证明）

### 1.2 财务信息

- 年度审计报告 / 财务报表
- 纳税证明 / 社保缴纳证明

### 1.3 人员库

- 人员档案（学历、职称、在职/社保状态）
- 执业与技能证书（建造师、PMP 等，含有效期）
- 人员项目经历（人员 ↔ 项目关联关系）

### 1.4 业绩案例库

- 证明原件（中标通知书、合同关键页、验收报告）
- 结构化业绩卡片（金额/时间/业主/项目类型标签）

### 1.5 其他资产

- 设备/仪器清单
- 软著、专利、检测报告

## 2. 历史标书与方案库

> 向量化重点区，章节粒度切分 + 元数据标签

### 2.1 完整历史标书归档

按行业 / 项目类型 / 中标结果归档。

### 2.2 章节级素材库

- 技术方案类（总体架构、实施方案、质量/进度/安全保障…）
- 商务应答类（报价说明、付款响应、偏离表写法）
- 通用章节类（售后服务、培训方案、保密应急承诺）

### 2.3 图表素材库

架构图、流程图、组织架构图、现场照片。

### 2.4 复盘知识

评审反馈、失分点分析、优秀应答范例。

## 3. 模板与写作框架库

> 模板文件 + 结构化配置

### 3.1 标书骨架模板

按行业划分：工程建设 / IT 信息化 / 政采服务…

### 3.2 格式排版模板

封面、目录、页眉页脚、字体装订规范。

### 3.3 写作策略库

评分点应答套路、加分项组织框架、常用话术。

## 4. 合规与规则库

> 规则引擎条目为主 + 少量检索型条款库

### 4.1 废标检测规则集

- 资格类（资质缺失、业绩不满足）
- 格式类（漏页、目录错、密封装订）
- 内容类（漏应答、负偏离、报价错误）
- 签署盖章类（签字、盖章、授权书）

### 4.2 法规政策库

招投标法、政府采购法、地方实施细则。

### 4.3 行业标准规范

国标/行标条款，供技术方案引用与校验。

## 5. 项目工作区

> 临时知识，随项目创建/归档，与长期库隔离

### 5.1 招标文件及解析结果

- 原文（含补遗、澄清答疑文件）
- 资格要求清单 + 评分办法（结构化）
- 技术需求点清单（需求 ↔ 应答映射表）
- 废标风险点标注

### 5.2 本项目定制素材

临时上传的方案、报价资料。

### 5.3 生成产物与人工修订记录

投标结束后 → 回流候选。

## 6. 外部情报库（可选，二期）

> 采集型，时效性强

### 6.1 业主画像

历史采购偏好、评审风格。

### 6.2 竞争对手情报

对手业绩、常用打法。
