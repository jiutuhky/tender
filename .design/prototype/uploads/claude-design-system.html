有四个我特别欣赏的反直觉决策：

第一，模型回复用衬线字体，用户输入用无衬线。前者气质是阅读

为什么 Claude 用衬线
claude.ai/blog/typography
"Serif slows the reader down, making them treat AI output as content to consider, not commands to execute."
，后者是操作。这一条字体选择，定义了"对话"和"指令"两种关系。

第二，行内代码用 danger-000（暗模式下偏粉红的红）。const x = 1 在文本流里跳出来，但又不像 "#ff0000" 那种刺眼的纯红。配合 .5px 的 hairline border，做出"贴纸"质感。

第三，Thinking 块的折叠用 CSS Grid grid-template-rows 过渡，不是传统的 max-height hack。这是 2023+ 的现代写法 —— 浏览器原生量取内容高度然后过渡，零 JS、零 ResizeObserver。CSS-Tricks

Animating CSS Grid
css-tricks.com/css-grid-animations
"Using grid-template-rows with auto values lets you animate height without knowing the content size in advance."

第四，亚像素 hover 位移。看下面：

css 
/* Retina 屏才感觉得到的"呼吸" */
.group:hover .group-hover\:-translate-y-[0.5px] {
  transform: translateY(-0.5px);
}

0.5px 的位移在普通屏上几乎不可见。但 Retina 用户会感受到一种"轻微呼吸"的反馈。这是给高 DPI 用户的隐形礼物。
