Frost 2 · 凝光
霜怎么升级成会折光的玻璃

Frost 1 的立场是「材质即层级」：玻璃靠厚薄区分前后。iOS 26 与澎湃 OS 4 之后，玻璃多了两个维度——光（棱、照明、折射，随交互走）与环境（玻璃知道自己压在什么上面并自调）。本方案把这两个维度接进 Frost，同时守住 Prose 作为招投标生产力工具的底线：内容永远实底，蓝只归可交互与进行中，可读性不让位于质感。

立场 1

材质即层级

保留。两种材质（凝 / 霜）× 三档厚度，取代原来靠白度硬分的四档。

立场 2 · 新

光即状态

棱光与照明说「这是一块可以按的东西」，高光跟指针、按下更亮、运行中光束绕框——光是白的，不占蓝。

立场 3 · 新

环境即上下文

玻璃取样背后的画面：落在深色上文字反相、棱光收敛；画布壁纸回归，让玻璃有东西可折。

01 · 调研

两家在做同一件事，但答案不同

Apple 把玻璃做成一种「元材料」：实时折射、镜面高光、随内容自适应、控件合并与形变。小米一年后跟进（HyperOS 3 液态玻璃 → 2026-08-13 澎湃 OS 4「柔光玻璃」），但立场偏向可读性：环境色感知自动调透明度、按压有光感、全局给「通透 / 柔和」两个模式让用户选。两家共同承认的教训：Apple 三个 beta 里把磨砂一路加厚，iOS 26.1 加了「着色」模式——纯通透的玻璃在生产力场景里是可读性负债。

iOS 26 · Liquid Glass

  • 三层模型：highlight（光的投射与移动）/ shadow（前后分离）/ illumination（材质对环境的响应）。
  • 折射不是模糊：毛玻璃散射光，Liquid Glass 弯曲光——边缘可以看见背后内容被拉伸、色散。
  • 玻璃只做导航与控制层，浮在内容之上；永远不施于内容本身（列表、表格、媒体）。
  • 玻璃不叠玻璃：玻璃取样不到另一块玻璃，多块相邻玻璃放进一个容器共享取样，靠近时合并（morph）。
  • 两种变体：Regular（默认，全场景自适应）/ Clear（只在照片、地图之类富媒体上，且前景要粗要亮）。
  • 同心圆角：内圆角 = 外圆角 − 内边距，控件与窗口/硬件圆角同心。
  • scroll edge：工具栏与内容交界处不画线，用渐进模糊与渐隐让内容「滑到玻璃下面去」。
  • 自适应着色：文字按背景调色、亮度、饱和；深色不是翻转，大面积玻璃不翻只调。
  • 无障碍：降低透明度 → 加厚磨砂；增强对比 → 描边实线；减少动态 → 关闭高光跟随。

澎湃 OS 4 · 柔光玻璃（2026-08-13）

  • 环境感知：分析壁纸、小组件与环境光，自动提取配色；强调色、字体、图标轮廓动态调对比。
  • 按内容调透明度：玻璃根据当前内容属性自动改通透度——质感与可读性并举，这是它对 Apple 最明确的修正。
  • 光感交互：感知用户操作，按控制中心图标有真实光影反馈；灵动光效随操作走。
  • 通透 / 柔和双模式：前者强调透明与折射，后者偏磨砂，全局可切。
  • 2.5D 图标：从扁平转成带微妙边缘高光的「精致实体薄片」；状态栏图标线条加粗。
  • 边缘柔化：所有系统控件边缘精细柔化，图层关系与动态层次更细腻。
  • 落点：锁屏时钟、系统控件、弹窗通知、控制中心——都是控制层，不是内容层。
借进来
  • 三层光学模型与折射——Frost 目前的玻璃只有「模糊 + 白底 + 顶部一条高光」，没有棱、没有照明。
  • 玻璃只做控制层 / 不叠玻璃 / 同心圆角 / scroll edge——这四条与 Frost「深度代替描边」天然同源。
  • 环境感知 + 按内容调透明度（澎湃）——Web 上可以用取样实现，比 Apple 的"全靠系统"更适合我们自己掌控。
  • 通透 / 柔和双模式（澎湃）——直接对应 prefers-reduced-transparency 与一个用户设置。
  • 光感交互——高光随指针、按下照明增强，取代目前「按下缩 3%」这一种反馈。
不借
  • Clear 变体——它的前提是照片/地图背景，Prose 背后是标书和矩阵卡，没有这种场景。
  • 随设备运动的镜面高光——桌面没有陀螺仪；指针就是我们的「光源」。
  • 壁纸驱动的全局配色（澎湃）——Frost 只有一种强调色，这条不动。
  • 2.5D 图标全面化——Phosphor regular 线性图标不动；只给 Bot 与 app icon 加薄片棱光。
  • 随处可见的玻璃——矩阵卡、文档纸面、Composer、抽屉条目列表永远实底。
02 · 诊断

Frost 1 的玻璃缺三样：光、环境、行为

产线里已经有一块真正会折光的玻璃（消息窗与智能体看板，本地移植的 LiquidGlass），但它是孤岛：没进 token 体系，其余十几处玻璃还是 Frost 1 的毛玻璃；而且 /workspace 的底色几乎无色——玻璃背后没有东西，折射与不折射看不出差别。下面同一块凝玻璃放在三种背景上：

把鼠标移到玻璃上看照明；把玻璃边缘对着纸片与色块看折射与色散。Safari / Firefox 不支持 backdrop-filter: url()，会退成纯毛玻璃——这与产线 LiquidGlass 的退化路径一致。

缺光

四档材质只有 --highlight-top 一条 1px 顶光。没有棱（边缘迎光 / 内反射），没有照明（材质内部的亮度分布），没有折射。它是磨砂亚克力，不是玻璃。

缺环境

壁纸只存在于品牌板；产线底色是近白渐变 + 点阵。玻璃不知道背后是深是浅，文字色写死，落到深色区域就不可读。

缺行为

玻璃是静态材质：hover 换底色，按下缩 3%，没有光的响应；消息窗 min→open 是尺寸插值不是合并；工具栏与滚动内容之间还是一条 1px 线。

03 · 材质体系 v2

两种材质 × 三档厚度，五层光学结构

Frost 1 按「用在哪」分四档（侧栏 / 工具栏 / 浮层 / 模态），靠白度硬分。v2 改成按「是什么」分：凝（lens）会折射、有棱光，给需要被看见、被按的控制层；霜（soft）是磨砂，给大面积的 chrome。厚度决定模糊半径、折射强度与投影三件事，一起走。

规则（新增于非协商项之后）

  • 1 · 玻璃只做控制层。内容永远实底；凝玻璃里能打字的地方仍是实底（Composer）。
  • 2 · 玻璃不叠玻璃。浮在玻璃上的浮层取样不到下层玻璃，会塌成透明板——凝·常落在霜·厚之上时底色自动加重到 tint-soft；相邻玻璃药丸共用一个容器，靠近即合并。
  • 3 · 一屏至多三面凝玻璃。SVG 位移滤镜按像素计费，大面积一律霜；超出配额的凝按厚→薄顺序降级为霜。
  • 4 · 转场期一律霜。尺寸逐帧变化时位移滤镜逐帧重跑，沿用 --lg-plain 机制，到位后再换回凝。
  • 5 · 光是白的。棱光、照明、镜面高光只用白与环境色；蓝仍只归可交互与进行中。运行中的光束是唯一例外（它本来就是「进行中」）。
  • 6 · 同心圆角。内圆角 = 外圆角 − 内边距。凝·厚面板 20 / 内边距 8 → 内控件 12；药丸一律 999。
  • 7 · 可读性底线。玻璃上文字对比 ≥ 4.5:1；环境感知翻转文字色；prefers-reduced-transparency 与用户「柔和」设置 → 全站霜。
  • 8 · 不新增循环动效。高光随指针（事件驱动）、按下 120ms 照明增强、合并 320ms 标准曲线；减少动态时高光跟随关闭。
04 · 光即状态

把指针当光源

Apple 的镜面高光随设备运动，桌面上没有陀螺仪——但有指针。悬停时镜面高光从指针方向照进玻璃，按下时照明增强 120ms 后回落，说的是「这是一块能按的东西」；配合现有的 scale(.97)，反馈从一维（缩）变成二维（缩 + 亮）。运行中的边框光束保留，它是 Frost 里唯一的循环，也是唯一允许带蓝的光。

05 · 环境即上下文

玻璃知道自己压在什么上面

澎湃 OS 4 的「感知环境颜色」在 Web 上可以用取样做：把壁纸渐变离屏画一遍，按玻璃元素的位置读平均亮度，低于阈值即翻转文字色、收敛棱光、把底色从白雾改成暗雾。拖动下面这块玻璃试试——文字色不是按位置写死的，是取样出来的。

毛玻璃 + 1px 线 → 霜·厚，边界改由 .5px 接触环与顶部内高光承担。

消息窗 / 快捷指令

消息窗保持凝·厚；快捷指令由 78% 白底方块升成凝·薄药丸，高光跟指针。

不动的

四张矩阵卡、Composer、抽屉条目、Bot 锚点、蓝的用法、字体、图标——全部原样。

09 · 落地路线

三步，每步可独立合入

P0地基 · 1 周
  • token 进 skill：tokens/materials.css 加 v2 token，guidelines/materials-glass.card.html 换成材质矩阵；readme「Material」一段改写为两种材质 × 三档。
  • 壁纸 v2 上画布：/workspace body 底换 --wallpaper-v2，点阵降 45%。这一步单独就能让现有 LiquidGlass 从「看不出」变成「看得出」。
  • LiquidGlass 收编为 <Glass material="lens">：位移滤镜三档共用一张贴图；rim / illum / shadow 改读 token；保留全部 backdrop-root 硬约束注释。
  • 双模式开关：data-glass 挂 html，reduced-transparency 自动 soft；先不做设置页，用 localStorage。
P1控制层 · 2 周
  • 凝·薄：活动条、快捷指令、dock chip、视口提示 → 药丸 + 指针高光 + 按下照明。
  • 凝·常：菜单、popover、toast、tooltip；实现规则 2（浮在霜上自动加重底色）。
  • 霜·厚：顶栏、活动栏、抽屉面、溯源预览遮罩——去掉 1px 边线，改接触环 + 顶部内高光。
  • scroll edge：artifact-header、画布工具栏、抽屉吸顶头、溯源标题栏。
  • 同心圆角审一遍：消息窗 20 → 内 12；抽屉 0 → 内卡 14 不变。
P2行为 · 2 周
  • 环境感知：壁纸离屏取样，先只给凝·薄与凝·常（小元素可翻）；消息窗与抽屉只调不翻。
  • 合并：活动条 ↔ 消息窗 open 的转场改成同一块玻璃长大（现在是两个元素交接）；转场期霜化沿用。
  • Bot 与 app icon 薄片棱光：借澎湃 2.5D 的边缘高光，只落在这两处。
  • 设置项：外观 / 玻璃模式 / 指针高光三个开关进用户设置。

性能护栏

  • 一屏 ≤ 3 面凝玻璃，超出降霜
  • 转场期霜化（data-tweening）
  • 取样 rAF 合帧，元素静止不取
  • backdrop 子树禁 mix-blend / opacity 动画 / isolation

可读性护栏

  • 玻璃上正文对比 ≥ 4.5:1，用 v2 壁纸的最深角实测
  • reduced-transparency → 全站霜 + 实底回退
  • increased-contrast → 棱光换成 1px 实线
  • 深色不是翻转：大面板只调不翻

浏览器

  • Chromium：完整（折射 + 色散）
  • Safari / Firefox：无位移，退成霜；棱光与照明仍在，所以仍比 Frost 1 有光
  • 无 backdrop-filter：实底 + 投影
