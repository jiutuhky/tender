# 0008. 结构化资产管理面：对象库为事实来源，agent 经 MCP 工具面读写

- 状态：已接受
- 日期：2026-07-13
- 关联：ADR 0007（project workspace 为文件层地基）；实施契约 `hagent/docs/specs/2026-07-13-structured-assets-mcp.md`；旧本体层 ADR 0001–0006 已于同日废弃删除，本决策不承接其结论

## 背景

应答矩阵、偏离表、大纲等**结构化资产**（一次投标 Project 内生的结构化工作产物）当前以普通文件形态活在 project workspace（`bid_response_matrix_*/final/*.json`），由 `bid-response-matrix` skill 自由写入。后果：变更无校验、无审计、无并发裁决；schema 契约散在 skill 文档里靠自觉遵守；人工确认/偏离标注这类贯穿编制期的状态无处安放（文件一重写即丢）；前端靠扫目录取数。用户提出架构级方向：这类资产应通过 MCP Server 创建、维护、管理，而非作为普通项目文件。

## 决策

1. **对象库为唯一事实来源**：结构化资产存 hagent 内对象库（SQLite 扩表），workspace 不再存放最终 JSON；文件形态只作按需生成的**导出投影**（只读、可再生、不回写）。
2. **管理面唯一写入口 + 双 adapter**：hagent 内立「结构化资产服务」，校验、审计、并发裁决集中于此；MCP server（FastMCP）是它面向 agent 的 adapter，REST router 是面向前端的 adapter（读 + 人工动作）。
3. **hagent 主 agent 是真 MCP client**：server 模式 loopback Streamable HTTP（绑 127.0.0.1 + Origin 校验），CLI host 模式同一 FastMCP 对象走 stdio。工具面全局仅一份，自家 agent 与未来外部 agent 同门同面；对外开放前必须补 auth。
4. **抽取全程工具化**：草稿区 staging → 批量提交（≤10 条/次）→ 行级修复 → 服务端确定性校验（结构/去重/源文保真）→ publish 门禁。chunk/done/merge_plan 中间文件退场；招标源文件经 document registry 注册（源文件本体仍是 workspace 普通文件）。
5. **发布后是活对象**：publish = 抽取质量门禁 + revision 快照点，非定稿封存；发布后行级变更（确认、偏离、应答状态）走受管工具，append-only 审计。补遗/澄清默认**增量维护**（行级 add/update/drop），全量重抽仅作明示丢弃人工状态的逃生门。
6. **首发范围**：只收应答矩阵一个对象域；偏离表 = 矩阵条目应答状态的投影视图（确认不存在矩阵之外的偏离行），不设独立实体；大纲推迟，工具命名以服务前缀 + 资源位留位。

## 备选与否决理由

- **文件为载体 + server 只管状态与索引**：双写结构，文件与状态各持一半真相；agent 保有文件写权即可绕过管理面，文件重写导致状态指针悬空。已否决。
- **MCP 唯一网关（前端也当 MCP client）**：叙事纯粹，但 UI 的查询/分页/订阅模式与 agent 动作模式是两种接口，为纯粹性付实用性税。已否决，收口移到服务层达成同等治理。
- **终点一次性导入（中间流程留在文件）**：合并与修复劳动在治理面外，审计只剩「最后进来一坨」；整包导入撞长 payload 概率性失败，最终仍要拆分——绕一圈回到全程工具化。已否决。
- **重解析对齐迁移（全量重抽 + 新旧条目身份对齐搬运人工状态）**：「两个条目是否同一条」是模糊匹配难题，工程量最大；增量维护路径下条目身份从未断裂，问题根本不出现。不做。
- **agent 走进程内工具绑定、MCP 只对外**：agent 面出现两个绑定靠纪律同步，MCP 面沦为无人日用的展窗。已否决。

## 后果

- 矩阵变更获得完整推导审计链（每笔 add/update/drop 带 actor、reason、前后值），偏离表导出与 revision 回溯同源。
- `bid-response-matrix` skill 瘦身保留（编排 + 抽取认知指南），三个校验脚本逻辑上移为服务层函数；抽取指南以 MCP resource 镜像（单一来源）供外部 client。
- 前端双轨过渡：过渡期 publish 顺手物化旧路径 JSON，前端切 REST 读 + 新触发后关闭物化。
- 矩阵脱离 project git 历史，版本与回溯改由 revision 快照 + 审计事件承担；workspace git（ADR 0007）继续管源文件与交付物。
- 引入 deepagents 侧 MCP client 接入这条新链路，CLI stdio 与 server loopback 两种 transport 需分别验证。
