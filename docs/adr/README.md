# 架构决策记录（ADR）

本目录记录 Prose 关键架构/产品决策，由设计 grilling 会话逐条产出。

## 约定

- 每敲定一个不可轻易回退的方向性决策 → 一份 ADR，文件名 `NNNN-短横线标题.md`，编号递增。
- 状态流转：`提议` → `已接受` / `已否决` / `已取代（by NNNN）`。
- 术语以 [`docs/ontology/glossary.md`](../ontology/glossary.md) 为准；ADR 中首次引入的新术语需同步回术语表。

## 模板

```markdown
# NNNN. <决策标题>

- 状态：提议 | 已接受 | 已否决 | 已取代（by NNNN）
- 日期：YYYY-MM-DD
- 关联：<相关 ADR / 文档 / issue>

## 背景
<为什么需要这个决策；当时的约束与事实>

## 决策
<我们决定……（用主动语态陈述）>

## 备选与否决理由
<认真考虑过的其他选项，以及为什么不选>

## 后果
<正面/负面后果；引入的新约束；需要跟进的事项>
```
