# Triage 标签

各 skill 以五个规范 triage 角色沟通。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签        | 含义                         |
| -------------------------- | ----------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`    | 维护者待评估                 |
| `needs-info`               | `needs-info`      | 等报告人补充信息             |
| `ready-for-agent`          | `ready-for-agent` | 规格完备，AFK agent 可接走   |
| `ready-for-human`          | `ready-for-human` | 需要人来实现                 |
| `wontfix`                  | `wontfix`         | 不做                         |

当 skill 提到某个角色（如「打上 AFK-ready 的 triage 标签」）时，使用上表对应的标签字符串。

若日后实际用词变化，改右列即可。
