# Tooltip

Small dark label on hover/focus. Wraps a single trigger; positions above by default.

```jsx
<Tooltip label="切换侧栏">
  <IconButton icon="sidebar-simple" label="侧栏" />
</Tooltip>
```

`side`: `top` · `bottom` · `left` · `right`. Keep text to a few words — for longer help use a popover instead.
