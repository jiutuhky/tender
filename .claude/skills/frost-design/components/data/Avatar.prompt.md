# Avatar

Rounded-square identity tile (continuous corners, matching the icon language). Shows an image or initials on a soft-blue tint; optional status dot.

```jsx
<Avatar name="周明" size={32} status="online" />
<Avatar src="/team/lin.jpg" name="林" size={40} />
```

`shape="squircle"` (default) keeps the macOS feel; use `shape="circle"` only in people-first contexts. Default size 32px.
