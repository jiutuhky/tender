# CONTEXT —— 产品前端

工作台画布(大纲视图)相关的领域词汇表。只收术语,不收实现细节。

## 画布

- **双模式**:画布的两种互斥呈现。**演示模式**(idle,静态 mockup 原型,仅直达 `/workspace` 且未启动解析时可见)与**真实模式**(解析启动或项目恢复后,呈现真实产物)。
- **应答矩阵卡**:真实模式下的四张核心制品卡——项目概要(basic_info)、商务应答矩阵(business)、技术应答矩阵(technical)、评分办法(scoring)。数据来自应答矩阵槽位。
- **主轴卡(大纲卡)**:mockup 里的「投标文件大纲」骨架卡。仅属演示模式;真实模式不出现(真实大纲未来由矩阵生成,登场时另立实体)。
- **中心舞台**:真实模式解析进行期间,四张应答矩阵卡以 2×2 四宫格居中呈现的阶段。全盘失败时定格于此。
- **停靠列**:矩阵生成完毕后,四卡沿画布最左侧自上而下(概要 → 商务 → 技术 → 评分)垂直排列的终局位置。
- **停靠(编排)**:从中心舞台飞往停靠列的一次性程序接管动画。只在亲历解析的浏览器会话中播放;恢复/刷新路径直接以停靠态呈现,不重放。停靠后卡位完全归还用户。
- **生成完毕**:四个矩阵槽位全部到达终态(ready 或 error)的时刻,是停靠的触发信号;与对话流是否收尾无关。
- **终态**:矩阵槽位的 ready 或 error 状态。error 计入终态,不阻塞编排。
- **解析中断**:流异常终止且存在未到终态的槽位时,卡面呈现的状态。区别于「解析中」(仍在进行)与「解析失败」(槽位 error)。

## 对话浮层

- **消息浮窗**:画布左上角承载智能体执行流的浮动窗口。三档尺寸——**胶囊**(只报一行状态,transcript 已卸载)、**常规**(380px)、**展开**(约半屏)。位置固定不可拖拽。胶囊态发送消息或解析出错时自动升回上次的开启档。
- **输入坞**:画布底部居中的浮动输入区。上方一行是**快捷指令**(有项目时才出现,点击预填输入框、不代发),运行期由活动条顶替。
- **活动条**:运行期浮在输入坞正上方的一行状态,报智能体此刻在做什么(如「正在提交矩阵条目 · 技术应答 · 4 次调用」),点击展开消息浮窗。它订阅的是派生字符串而非时间线,内容不变即不重渲。
- **材质分工(Frost)**:能读、能打字的地方实底(浮窗正文、Composer),只报状态或做快捷入口的地方走玻璃(胶囊、活动条、快捷指令)。浮窗正文不得半透明——思考块时间线竖线靠 `var(--surface)` 的不透明外环遮断。

## 卡面与详情

- **决策触发器**:每张卡面预览必须亮出的、驱动用户「要不要点开细看」的关键信号——截止时间(概要)、实质性条款数(商务/技术)、高风险条目数(技术)、分值结构(评分)。
- **实质性条款**:招标文件中带 ★ / mandatory 标记、不满足即废标的条款。UI 中恒用橙/红系警示色。
- **抽屉详情**:点卡后从右侧滑入的完整视图,是「展开详情」的唯一形态。
- **人工动作**:抽屉条目行上的「确认」与应答状态标注(合规/正偏离/负偏离),直接落 hagent 对象库并留审计(actor=user);区别于智能体经工具面的写入。

## 溯源预览

- **溯源预览(原文预览层)**:点击来源签后,盖满画布的招标文件原文阅读层([[抽屉详情]]留在层后不卸载,退层即回到条目列表原样)。挂在 `.cv-drawer` 子级 —— 它已是 absolute inset:0 / z-30 铺满画布,所以无需 portal、无需越过页面级 fixed 层。形态取代了早期的「抽屉加宽对照双栏 + 窄屏二级视图」:双栏留给原文的版心只有 ~503px,而[[文档纸面]]排版与招标文件宽表格都要 720px 以上,版心不够是排版做不出来的硬原因。Esc 语义改为**逐层退**(先退层、再关抽屉),判定收在 CanvasDrawer 的单一 window 处理器里(两个监听器会互抢,同节点上 stopPropagation 拦不住彼此);Tab 焦点陷阱同一时刻只允许一个,层开着时抽屉那份短路让位。
- **对照条**:预览层标题栏下方钉住的「正在核验什么」—— 条目编号 + 要求原文(两行截断可展开)+ 人工动作(确认 / 合规 / 正偏离 / 负偏离)+ [[来源步进器]]。预览层盖住条目列表会切断「对照原文核验并就地落应答状态」,对照条是这条能力的补偿。数据是纯 payload(`TraceClaim`),行级状态由对照条按 matrixType + itemId 从 store 读实时值 —— **不能塞 ReactNode 快照**,否则层内点完确认自己不刷新。
- **来源步进器**:对照条右侧的「第 N/M 条来源 ‹ ›」,在同一条目的多条 source_refs 内环绕移动并自动跳过不可用来源(与来源签置灰同口径),不用退层再找下一枚签。
- **文档纸面**:原文落在冷灰舞台(`.cv-trace-stage`,同时是定位滚动的容器)上的白纸(`.cv-trace-sheet`,760px 宽 / 72px 天地白边),层级密度取原型「文档预览与导出」的 `.page`。**不伪造 A4 分页** —— 源是线性 Markdown 抽取,没有页边界,硬分页会造出一张几十屏高的假页;要的是纸面质感,不是页断点。
- **来源签**:条目行/评分表/否决项上由 source_ref(document_id + line_span)升级成的可点击签(如「L120-124 · 技术需求」),是溯源预览的唯一触发器。document_id 不在文档注册表时置灰不可点。
- **活跃 ref**:全局同一时刻至多一条、当前被定位与高亮的 source_ref;点任何来源签即切换活跃 ref,旧高亮清除。
- **高亮选区**:活跃 ref 的 line_span 与渲染块相交的**块级**高亮(原文按渲染态呈现,源行号标注在块级元素上;命中大表格即整表高亮——表格由管线套在可横滚容器里,行号打在容器上)。行号越界/缺失时照常打开文档,黄条提示不定位。
- **文档注册表**:hagent 侧 document_id → workspace 文件路径(含 sha256)的项目级映射,溯源预览解析来源签的依据。
- **溯源动效语汇**:预览层入场 = 遮罩淡入 + 面板 scale .98→1 到位(只动 transform / opacity);退场取镜像,缓动用 Frost 标准曲线的镜像控制点(1,0,.68,.28)——镜像曲线是标准缓动对可逆过渡的合法延伸,常量收在 canvas/traceMotion.ts。**到场让位**保留:缓存命中时整篇文档会在入场途中 commit,长帧会冻住动画,所以浮层落位前持骨架。
- **原文渲染管线**:`lib/trace/pipeline.ts` 的 unified 管线(remark-parse / gfm / math → remark-rehype → **rehype-raw** → rehype-sanitize → rehype-katex → 行号锚点)。三处顺序是刻意的:`rehype-raw` 用真 HTML 解析器接管 MinerU 表格(其单元格正文含硬换行,早期按「每行以 < 开头」吞 HTML 块的手写分段器会把一张表切成未闭合残片 + 一堆带字面量 `</td><td>` 的段落——全语料 69 张表破 17 张、泄漏 52 行);`rehype-sanitize` 必须在 `rehype-katex` **之前**(净化对象是语料里的 HTML,KaTeX 自己产的 MathML 是可信产物,洗掉就丢了无障碍标注);行号锚点必须最后,且**只打 root 层子节点**——打到嵌套节点会把整块高亮碎成片。行号取 hast 节点原生 `position`,与 line_span 同坐标系。
- **公式呈现**:`$…$` 经 KaTeX 渲染(反转了早期「OCR 噪声,如实按文本呈现」的决策)。语料里约三分之二是合法算式(`$20 \%$`→20%、`$\textcircled{1}$`→①、`$7{\times}24$`→7×24),其余是引号被误识别成哥特体上标的 OCR 讹误,渲染结果内容仍错但比裸 LaTeX 可读。KaTeX 结构样式必须引入(它把 `.katex-mathml` 裁成 1px,否则 MathML 与 HTML 会同一公式渲染两遍),但其 9 个 KaTeX_* 字族在 globals.css 里被覆盖成文档字体栈——**「零 Web 字体」不为算式开第二次口子**,20 个 woff2 一个都不会被请求。
