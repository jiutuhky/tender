# PDF 原文溯源契约

用户上传 PDF 后，后端调用 PaddleOCR HPS 的 Triton HTTP 接口，生成只读 Markdown、版面映射、原件与预览 PDF。大模型消费 Markdown，来源引用继续使用 `document_id + line_span`；前端在 PDF 原页上显示对应版面区域。

## 入库与版本

`HAGENT_OCR_BASE_URL` 为 HPS 根地址，当前部署为 `http://10.13.13.3:8000`，其后拼接 `/v2/models/layout-parsing/infer` 或 `/v2/models/restructure-pages/infer`。请求使用 BYTES 张量的双层 JSON，必须同时检查 HTTP 状态与业务 `errorCode`。显式关闭方向分类、去畸变及可视化输出。独立重构保留分页，`markdown.images` 映射到 `markdownImages`，跨页关系来自 `global_group_id`。

原件与预览件存于 `HAGENT_BLOB_ROOT`，Markdown 与 sidecar 存于项目的 `sources/`。同名文件产生不同解析文本时另存含哈希的路径，保留旧引用。相同 Markdown 已绑定其他原件时拒绝覆盖；同一项目的进行中入库任务不接受第二次上传。连接失败直接报告，文件识别失败按页隔离；返回页数不符时缩小批次重新确认页序，不假定遗漏发生在末尾。全部页失败不注册文档。

## sidecar schema 2

```json
{
  "schema": 2,
  "coordinateSpace": "page-display-normalized",
  "mdSha256": "Markdown UTF-8 字节的 SHA-256",
  "originSha256": "上传原件的 SHA-256",
  "previewSha256": "预览 PDF 的 SHA-256",
  "mdLineCount": 120,
  "pages": [{"index": 0, "width": 1191, "height": 1684}],
  "blocks": [{
    "mdStart": 10, "mdEnd": 12, "label": "text",
    "rects": [{"page": 0, "bbox": [0.1, 0.2, 0.8, 0.3]}]
  }]
}
```

页码从 0 开始，Markdown 行号从 1 开始且区间闭合。矩形为 `[left, top, right, bottom]`，左上角原点、归一化到 0–1。宽高为 OCR 页面图像尺寸，失败页采用原页显示比例；不得把它们当作 PDF 用户空间坐标。

坐标对应裁切及 PDF 固有旋转之后的页面显示空间。前端直接乘 PDF.js viewport 的 CSS 宽高，设备像素比只用于 Canvas 清晰度。预览生成比较逐页 MediaBox、CropBox、Rotate、UserUnit；不一致时使用原件。前端另校验页数与显示比例，允许 0.5% 栅格取整误差。

行号按服务端 Markdown 与版面块顺序精确对齐；无法对齐的页保留文本，停止产出该页的定位映射。跨页组中出现无法对齐或无效矩形的成员时，整个组停止提供高亮。一条引用可对应多个页内矩形。缺失、越界、倒置、非有限坐标和版本失配都不得通过猜测定位。

schema 1 是历史未绑定产物，仅提供阅读；重新解析生成 schema 2 后可启用区域定位。纯 Markdown 文档沿用 Markdown 行号预览。

## HTTP 读取

项目文档列表提供 `has_preview`、`origin_sha256`、`preview_sha256`。浏览器通过 Next.js 的 `/api/hagent/projects/{pid}/documents/{doc_id}/{kind}` 同源代理读取以下后端路径：

| 路径 | 用途 |
|---|---|
| `/projects/{pid}/documents/{doc_id}/preview` | GET/HEAD，预览 PDF |
| `/projects/{pid}/documents/{doc_id}/original` | GET/HEAD，原件下载 |
| `/projects/{pid}/documents/{doc_id}/sidecar` | GET，版面映射 |

PDF 端点支持 Range、If-Range，保留 206/416、Content-Range、Content-Length、Accept-Ranges 与基于内容哈希的 ETag。映射读取时检查实际 Markdown 哈希与注册记录、原件、预览件绑定；失配返回 409。文档或文件缺失返回 404，项目归属和鉴权与文档注册表一致。

## 浏览器资源与验收

PDF.js 固定 `6.3.289`，`predev`/`prebuild` 将同版本 Worker、CMap、标准字体与 WASM 同步到 `public/pdfjs/6.3.289/`；该目录为构建产物，不提交。阅读器按需载入，引擎资源走同源。可见页及前后各一页分配 Canvas，其他页保留几何占位；关闭释放文档、Worker 与页面位图。

前端质量门：`pnpm typecheck`、`pnpm lint`、`pnpm test:trace`。后端覆盖 `tests/ingest/`、`tests/server/test_document_carriers_api.py`、`tests/server/test_pdf_upload_and_progress.py`。真实样例用于检查排版、跨页表格与页面遍历，几何与异常用例同时覆盖混合尺寸、裁切、旋转、页面单位和失败页，不依赖样例模板。
