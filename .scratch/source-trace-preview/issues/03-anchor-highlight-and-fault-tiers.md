# 03 定位高亮 + 分层容错收口

## Parent

`.scratch/source-trace-preview/PRD.md`

## What to build

点击来源签后，原文面板滚动定位到 line_span 对应区域并**块级高亮**（渲染管线保留源码 position，把源行号锚点钉到块级元素上；与活跃 ref 行区相交的块整块高亮，命中单行大表格即整表高亮，高亮用系统蓝浅染 + 左缘蓝条）。全局同一时刻至多一个**活跃 ref**：点任何签即切换定位与高亮、旧高亮清除、活跃签点亮。

溯源纯逻辑（签可用性判定、源行号→渲染块映射、容错分层判定）收进 lib 层纯模块，组件只消费。分层容错在本票整体收口：注册表缺 document_id → 签置灰 + 悬停原因说明；文件读取失败 → 面板内错误态 + 重试入口；line_span 缺失/越界 → 照常打开文档、顶部黄条「未能定位」、不滚动不高亮。坏数据必须可见，不静默吞掉。

## Acceptance criteria

- [ ] 点签滚动定位到高亮区（进入视野中部），块级高亮与 line_span 相交语义正确；表格行命中整表高亮
- [ ] 全局单活跃 ref：切换签时旧高亮清除、新签点亮，状态放抽屉层局部状态/context，不进全局 workspace store
- [ ] 行号→块映射、ref 解析、容错分层判定收在 lib 纯模块，strict typecheck 通过
- [ ] 三类容错态齐备且互不串扰：置灰签悬停说明、面板错误态可重试、越界黄条照开文档
- [ ] `prefers-reduced-motion` 下滚动定位为即时跳转
- [ ] `pnpm typecheck` + `pnpm lint` 通过；真语料实跑可演示「定位高亮 + 三容错态」
